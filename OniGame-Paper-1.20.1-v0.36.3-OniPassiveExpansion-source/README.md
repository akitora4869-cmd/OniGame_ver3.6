## 導入

1. Java 17で `mvn clean package` を実行します。
2. `target/OniGame-0.25.0.jar` をPaper 1.20.1サーバーの `plugins` に入れます。
3. サーバーを起動します。

## 初期設定（OP）

立っている場所を各地点として登録します。

```
/og set lobby
/og set player
/og set oni
/og set exit
```

心臓にしたいブロック位置に立って `/og heart` を実行します。複数登録できます。同じ位置でもう一度実行すると削除します。

## GM操作本と心臓配置

`/og gmbook` でクリック操作できるGM本を受け取れます。本からランダム配置・手動配置の切り替え、心臓マーカー取得、マーカー数確認、鬼種別のゲーム開始、停止を操作できます。

- ランダム配置：`/og heart` で登録した候補から `config.yml` の `random-heart-count` 個を抽選します。
- 手動配置：GM本から受け取ったアーマースタンドを置くと「鬼の心臓地点」という名前になり、即座に透明・固定・無敵になります。ゲーム開始時、その全地点に心臓が生成されます。

## 鬼設定チェスト

ロビーでチェストへ視点を合わせ、OPが `/og onichest` を実行すると鬼設定チェストとして登録されます。右クリックすると鬼構成UIが開き、堕狐／鬼神の選択、固有スキルと心臓による弱体化の説明確認、鬼パッシブ最大4個の選択ができます。GM操作本からもチェスト登録とUI表示ができます。

- 渇望：追跡が5秒続くごとに加速し、追跡終了時に解除
- 血嗅：負傷したぷれいやーを一定間隔で短時間発光
- 守護：心臓損壊時の通知間隔を短縮
- 捕食：各ぷれいやーを初めて瀕死・脱落させた際にスタミナ回復
- 妨害：心臓損壊の成功判定幅を狭め、通常成功時に進行を後退

心臓損壊のスキルチェックは、緑色の通常成功域と中央の金色グレイト域に分かれます。妨害なしでは通常成功で追加進行3、グレイトで追加進行7です。「妨害」が有効な試合中だけ判定幅が70%になり、通常成功すると進行が2後退します。グレイトは妨害中でも追加進行7を維持します。数値はすべて `config.yml` で変更できます。

鬼Bot戦では、Bot戦を開始したGMが鬼設定チェストで選んだパッシブ構成を鬼Botが使用します。

## 堕狐リソースパック

`OniGame-ResourcePack-v11.zip` を各プレイヤーへ適用してください。堕狐になるとチェーン装備一式が自動装着され、専用の外見になります。装備は試合中に外したり捨てたりできず、試合終了時に自動解除されます。この方式では通常のチェーン装備も堕狐と同じ着用外見になるため、本ゲーム内ではチェーン装備を堕狐専用として扱ってください。インベントリ内ではCustomModelDataにより頭・胴・脚・靴がそれぞれ専用アイコンになり、鬼選択UIの堕狐にも頭装備の `dakoface` が表示されます。

## 参加者0人でのテスト

誰も `/og join` していない状態で、ゲーム内のGMが `/og start dakko` または `/og start kishin` を実行するとソロテストモードになります。ロビー、ぷれいやー開始地点、鬼開始地点、出口、心臓地点は未設定でも開始できます。未設定地点はGMの現在地を基準に一時補完され、心臓地点が1つもなければ前方へ3個を仮生成します。保存済み設定は変更されず、仮生成した心臓はテスト終了時またはプラグイン停止時に撤去されます。

ソロテスト開始時にはホットバー9番へ「テストプレイ本」が自動配布されます。本から視線先の心臓を即時破壊、BGM再生・停止、状態確認、テスト終了ができます。心臓の即時破壊はソロテストを開始したGM本人だけが利用でき、通常試合では使用できません。本を失った場合は `/og testbook` で再取得できます。

### ぷれいやー対鬼Bot戦

`/og join`で参加した後、GMが `/og botgame dakko` または `/og botgame kishin` を実行すると、参加者全員がぷれいやー陣営となり、鬼Botと通常ルールで対戦できます。参加者0人ならGM本人に味方ぷれいやーBot 4体を加えた5人編成で開始します。GM本の「ぷれいやーBotテスト」ページからも開始できます。Bot本体と名前表示は透明になり、武器・防具だけが見えます。鬼Botは最寄りの生存ぷれいやーを索敵・追跡・攻撃し、堕狐は簡易テレポート、鬼神は簡易突進を使用します。スタミナ切れ時には追跡を一時休止します。外部プラグインは不要です。

鬼Botの索敵候補には実プレイヤーとぷれいやーBotの両方が含まれます。同じZombie系エンティティ同士でも確実に戦闘できるよう、ぷれいやーBotを追う際は専用の追跡・近接攻撃制御を使用します。鬼Bot版の狐火・天来・鬼神の突進もぷれいやーBotを対象にします。

### 鬼対ぷれいやーBot戦

参加者0人で `/og onibotgame dakko` または `/og onibotgame kishin` を実行すると、GMが鬼となり、標準5体のぷれいやーBotと対戦できます。末尾に1～8を指定すれば人数を変更できます。ぷれいやーBotは本体が透明で、茶色の革装備一式と鉄のツルハシだけが見えます。

ぷれいやーBotには役割別に「疾走・煙幕・破鬼撃・執念・治療」が割り当てられます。鬼との距離、逃走・討伐状態、残り体力を判断してスキルを自動使用します。

ぷれいやーBotはAIを有効にしたZombieへPaperの経路探索を設定して移動します。心臓・逃走地点・出口・討伐対象までの経路を計算し、壁や1ブロック段差を通常のMobと同様に迂回・昇降します。Bot同士は距離を取り、未破壊の心臓へ分散して向かいます。標準Zombieの攻撃対象選択は無効化され、プラグインが許可した鬼への攻撃だけが発生します。約6秒間まったく動けない場合のみ、進行方向にある近くの安全な床へ復帰します。

各ぷれいやーBotは「メインスキル1つ＋パッシブ2つ」を所持します。標準5体には、伊神京也（破鬼撃／神喰・強靭）、字那美咲（疾走／軽足・深呼吸）、有川風香（煙幕／臆病・退魔）、字那美蓮（執念／軽足・強靭）、佐倉夏海（治療／集中・絆）を自動割り当てします。神喰の攻撃補正、強靭の最大体力、退魔の心臓進行、集中のスキルチェック、軽足・深呼吸のスタミナ、臆病の逃走補正がBotにも反映されます。

佐倉夏海（サクラナツミ）プリセットはメイン「治療」、パッシブ「集中」「絆」です。治療は通常、自分だけを回復します。「絆」を装備して治療を完了すると、半径6ブロック以内にいる負傷した生存仲間も同じ量だけ回復します。使い切りアイテムの包帯では絆は発動しません。プリセット説明のセリフは「治療は私に任せて！」です。

ぷれいやーBotは心臓を自動探索して、人間のぷれいやーと同じ速度で継続的に損壊します。4～9秒ごとにスキルチェックが発生し、標準78％の確率で成功します。成功時は進行ボーナス、失敗時は損壊進行の後退・爆発音・鬼への方角通知が発生します。鬼が10ブロック以内へ接近すると心臓作業を中断して逃走し、すべての心臓を破壊すると脱出か鬼討伐を選びます。死亡・脱出は通常の勝敗判定に含まれます。

全心臓破壊後は、体力60％以上のBotが状況を再評価します。生存Botが2体以上いるか、鬼の体力が50％以下なら鬼へ向かって攻撃し、それ以外は出口へ退避します。判断基準・攻撃力・攻撃間隔は `config.yml` から変更できます。

## 鬼の心臓加護

心臓が1個以上残っている間、鬼と鬼Botは受けるダメージが標準で25％になり、毎秒体力1.0を自動回復します。最後の心臓が破壊されると、ダメージ軽減と自動再生は完全に解除されます。`config.yml` の `oni-heart-protection` で調整できます。

## スタミナ

満腹度ゲージを最大20のスタミナとして使用します。走りながら移動すると毎秒2.0消費し、止まる・歩くと毎秒1.5、しゃがむと毎秒2.5回復します。0になると走行が解除されます。鬼とぷれいやーの両方に適用され、数値は `config.yml` の `stamina` で変更できます。

走りながらジャンプすると、通常の走行消費とは別にスタミナを5.0消費し、1秒間の鈍足が付与されます。連続ダッシュジャンプは短時間でスタミナ切れになるため、平地では通常のダッシュを使う方が有利です。

`auto-step.enabled`が有効な間は、鬼とぷれいやーのどちらも馬のように高さ1ブロックの段差をジャンプせず乗り越えられます。フェンスなど1ブロックを超える障害物には適用されません。

## 選択UI

`/og join`すると、ぷれいやースキル選択用のチェストUIが自動で開きます。`/og skills`でも再表示でき、7種類のメインスキルをアイテムから選択できます。GMはGM本の「鬼を選択」または `/og onimenu` から堕狐・鬼神を選び、「選択した鬼で開始」でゲームを開始できます。従来の `/og skill` と `/og start dakko|kishin` も引き続き利用できます。

「疾走」は使用すると5秒間速度上昇IIIになり、クールタイムは35秒です。「安定着地」は手動使用せず、通常なら落下ダメージを受ける着地時に自動発動します。その落下ダメージを無効化し、4秒間速度上昇IIIを付与します。安定着地のクールタイムは疾走より短い20秒で、クールタイム中の落下ダメージは通常どおり受けます。

## 移動速度

標準設定はぷれいやー `0.20`、鬼 `0.24` です。直線では鬼が徐々に追いつくため、ぷれいやーはスキル・妨害アイテム・地形を使って距離を作る必要があります。速度は `config.yml` の `player-walk-speed` と `oni-walk-speed` で調整できます。

## ホラー・追跡システム

鬼が28ブロック以内に近づくと接近距離に応じた心音が鳴ります。鬼の24ブロック以内・視野110度・遮蔽物なしの条件で発見されると、警告タイトル・暗転・警告音とともに追跡状態へ入ります。鬼の視界を8秒間切ると追跡を解除できます。数値は `oni-terror-radius`、`oni-detection-range`、`oni-field-of-view`、`chase-lost-seconds` で変更できます。

## 心臓の進行作業

心臓は通常の採掘では破壊できません。心臓を右クリックすると作業を開始し、その場にいる間は自動で進行します。もう一度右クリックする、3.5ブロック以上離れる、攻撃を受けると中断します。初期設定は耐久100・0.5秒ごとに1進行なので、1人なら約50秒、複数人なら協力人数に応じて短縮されます。

作業中は4～9秒ごとに不定期のスキルチェックが発生します。画面下の白いカーソルが緑の成功範囲へ入った瞬間にSHIFTを押してください。成功すると3進行のボーナス、早すぎる・遅すぎる・無入力の場合は8進行後退し、大きな音と方角が鬼へ通知されます。通常の作業音による方角通知は5秒間隔です。

## 最終局面BGM

すべての心臓が破壊されると、全参加者へリソースパック内の `onigame:final_phase` が再生されます。収録音源は「名もなき剣」（メタデータ上のアーティスト: ulala）で、長さは約193秒です。ゲーム終了時には自動停止します。`/og bgmtest` で試聴、`/og bgmstop` で停止できます。別のサウンドIDへ変える場合は `/og bgm <ID>` を使用します。

## 遊び方

```
/og join
/og skill sprint
/og start dakko
```

スキルは `sprint`, `invisible`, `smoke`, `strike`, `heal`。鬼は `dakko` または `kishin` です。鬼種を省略するとランダムになります。右クリックで配布されたスキルを使用します。

## 回復スキルと互換アイテム

スキル選択UIへ「治癒」を追加しました。治癒を右クリックするとその場で5秒間の回復作業を開始し、画面下に回復ゲージが表示されます。完了すると体力を8回復します。約0.45ブロック以上移動するか、ダメージを受けると中断されます。クールダウンは45秒です。

既存スキルより少し弱い使い切りアイテムは、マップ内へランダム配置されるルートチェストから入手します。試合開始時の直接配布は行いません。

- 軽量薬：3秒間、疾走より弱い速度上昇
- 薄明薬：3秒間の透明化
- 小型煙玉：狭い範囲へ短時間の煙幕
- 破鬼符：破鬼撃より低いダメージとノックバック
- 包帯：8秒間の回復ゲージ完了後、体力を5回復

包帯は回復が完了した場合だけ消費されます。回復量・必要時間・移動許容距離は`config.yml`の`healing`で変更できます。治癒は `/og skill heal` でも選択できます。

## 個別ルートチェスト

ルートチェストを初めて右クリックすると、約5秒間の開錠ゲージが始まります。その場から離れるかダメージを受けると中断します。開錠に成功した本人は、同じチェストを次回からゲージなしで即座に開けます。

開錠状態・チェストの中身・取得状況はぷれいやーごとに完全に独立しています。誰かがアイテムを取っても、ほかのぷれいやーの中身は減りません。鬼はチェストを開けられません。

使い切りアイテムは種類に関係なく合計3個まで所持できます。3個持っている状態では、ルートチェストやドロップから4個目を取得できません。

GMはチェスト候補地点に立ち、`/og chest`で候補を追加・削除できます。`/og chests`で登録数を確認できます。登録候補から毎試合`random-loot-chest-count`個をランダム抽選します。候補が1件もない場合は、選ばれた心臓の周辺に自動配置します。GM操作本からも候補登録と確認ができます。

## ロビーのスキル設定チェスト

ロビー中は全プレイヤーの満腹度が20に固定され、落下・窒息・炎・溶岩・モブなど、原因を問わずダメージを受けません。ゲーム開始後は通常のゲーム用ダメージとスタミナ処理へ切り替わります。

ロビーへ通常のチェストを設置し、そのチェストへ視点を合わせて`/og skillchest`を実行すると、スキル設定チェストとして登録できます。ロビー中に右クリックすると構成UIが開きます。従来どおり`/og skills`でも開けます。

GUI上段の青い枠がメインスキル、下段の緑の枠がパッシブスキルです。メインは疾走・隠形・煙幕・破鬼撃・治療・執念・安定着地から1個、パッシブは8種類から2個まで選択できます。

- 執念：使用者と鬼を8秒間発光させます。鬼の輪郭は全プレイヤーから壁越しに視認でき、クールダウンは35秒です。

- 軽足：走行中のスタミナ消費を15％軽減
- 深呼吸：歩行・停止・しゃがみ中のスタミナ回復量を25％増加
- 集中：心臓スキルチェックの成功範囲と回復作業の移動許容距離を拡大
- 神喰：鬼への与ダメージを20%増加
- 強靭：最大体力を20から30へ増加
- 退魔：鬼の心臓を損壊する作業速度を15％増加
- 臆病：スニーク中の移動速度を通常歩行より少し遅い程度まで上昇

プリセット「伊神京也（イガミキョウヤ）」をクリックすると、メイン「破鬼撃」、パッシブ「神喰」「強靭」が一括で設定されます。「神喰」と「強靭」は通常のパッシブ一覧から個別に選ぶこともできます。
